Java Backend Career Workbook

공부한 내용을 취업할 수 있는 증거로 만드세요.

사내 업무관리 시스템을 직접 설계하고 구현하며 Java와 Spring Boot를 익히는 워크북입니다. 아래 순서대로 따라가면 코드, 테스트, Git 기록, 포트폴리오 문서와 면접 답변이 하나의 프로젝트로 연결됩니다.

처음부터 시작하기 40개 챕터 보기 진행 기록 열기
이 저장소는 학습용 워크북입니다.

Java 파일은 완성 애플리케이션이 아니라 빈칸이 있는 코드 조각입니다. 풀이를 마친 뒤 본인의 실행 가능한 Spring Boot 프로젝트에 다시 구현하고 테스트해야 포트폴리오 증거가 됩니다.

One Learning Session

오늘 60분만 따라가기

매번 같은 루프로 끝내면 학습량이 실제 포트폴리오 진척으로 바뀝니다.

  1. 0–05분오늘 끝낼 FR ID와 챕터 하나를 고릅니다.
  2. 5–20분문제와 Hard 코드로 먼저 직접 풉니다.
  3. 20–40분Starter와 해설로 빠진 개념을 확인합니다.
  4. 40–55분실행 프로젝트에 구현하고 테스트합니다.
  5. 55–60분검증 명령, 커밋, 배운 점을 증거 ID에 기록합니다.

챕터 완료 기준

빈칸을 채우거나 해설을 읽은 것만으로 완료하지 않습니다. 면접에서 확인시킬 수 있는 결과가 남아야 합니다.

반드시 남길 다섯 가지

  • 본인의 실행 프로젝트에 작성한 코드 위치
  • 성공과 실패를 검증한 테스트 코드
  • 실제로 통과한 테스트 또는 빌드 명령
  • 한 가지 의도가 드러나는 커밋이나 PR
  • 선택 이유와 대안을 설명하는 면접 한 문장
증거 기록하기

막혔을 때 확인할 순서

  • 실제 오류 메시지와 실패한 입력을 먼저 기록합니다.
  • Starter에서 호출 순서와 계층 책임을 확인합니다.
  • PRD / TRD에서 요구사항과 업무 규칙을 확인합니다.
  • 마지막에 해설을 읽고 본인 말로 다시 설명합니다.
  • 해결 과정은 트러블슈팅 증거 ID로 남깁니다.
