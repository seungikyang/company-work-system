34-2|AuthenticationPrincipal과 사용자 정의 CurrentUser를 구분한 것은?|전자는 Security 인증 principal을 해석하고 후자는 프로젝트의 등록된 해석기가 정한 세션·principal 규칙을 따른다.|CurrentUser라는 이름이면 해석기 없이 자동으로 사용자 ID를 얻는다.|AuthenticationPrincipal은 언제나 모든 Entity를 DB에서 조회한다.|두 어노테이션이 어떤 구성에서도 반드시 같은 값을 반환한다.|어노테이션 이름보다 실제 해석기와 인증 자료의 출처를 확인한다. 반환 자료형과 누락 처리를 명시한다.
34-3|Servlet Filter와 MVC Interceptor의 일반적인 진입 순서는?|요청이 필터 체인을 지나 DispatcherServlet에 들어온 뒤 매핑된 핸들러의 Interceptor가 동작한다.|Interceptor가 모든 요청에서 필터보다 먼저 실행된다.|Filter는 Entity를 저장할 때만 실행된다.|Interceptor와 Filter는 등록 여부와 관계없이 모두 실행된다.|HTTP 필터와 MVC 핸들러 처리의 범위를 구분한다. 응답 복귀 순서와 제외 경로는 등록 구성에 따라 확인한다.
