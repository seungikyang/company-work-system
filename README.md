# Java 백엔드 취업 포트폴리오 워크북

사내 업무관리 시스템을 직접 설계하고 구현하면서 Java·Spring Boot 백엔드 취업에 필요한 결과물을 만드는 실습형 워크북입니다.

이 저장소의 목표는 빈칸 문제를 모두 푸는 것이 아닙니다. 아래 다섯 가지를 면접에서 설명할 수 있는 본인 프로젝트로 남기는 것이 최종 목표입니다.

- 실행 가능한 사내 업무관리 시스템
- 핵심 업무 규칙을 검증하는 테스트
- 구현 의도가 드러나는 커밋과 Pull Request
- README, ERD, API 명세, 트러블슈팅 문서
- 프로젝트 선택과 기술 설계를 설명하는 면접 답변

## 대상

- Java와 Spring Boot 기본 문법을 배운 뒤 포트폴리오 프로젝트가 필요한 사람
- CRUD를 넘어 승인·반려, 권한, 상태 전이, 트랜잭션을 연습하려는 신입·주니어 개발자
- SI·기업용 업무 시스템 백엔드 직무를 준비하는 사람

## 먼저 알아둘 점

`practice/starter/`와 `practice/hard/`의 Java 파일은 컴파일 가능한 완성 프로젝트가 아니라 핵심 로직을 직접 채우기 위한 코드 조각입니다. 정답을 복사해 제출하는 대신, 워크북에서 이해한 내용을 본인의 실행 가능한 Spring Boot 프로젝트에 다시 구현해야 합니다.

## 시작 순서

1. [취업 준비 통합 워크북](./practice/job-preparation-workbook.md)에 목표 직무, 마감일, 현재 수준을 적습니다.
2. [PRD/TRD](./company_work_system_PRD_TRD.md)에서 구현할 제품과 기술 기준을 확인합니다.
3. [기능 구현 워크북](./practice/feature-implementation-workbook.md)에서 하나의 FR ID를 고릅니다.
4. [문제 목록](./practice/problems.md)과 `starter/` 또는 `hard/` 파일로 직접 풉니다.
5. 본인 프로젝트에 기능과 테스트를 구현하고 검증 명령을 실행합니다.
6. 통합 워크북에 코드 위치, 테스트 결과, 커밋, 배운 점을 기록합니다.
7. 막힌 부분만 [정답과 해설](./practice/answers.md)에서 확인한 뒤 본인 말로 다시 설명합니다.

## 취업 결과물로 연결되는 학습 흐름

| 단계 | 하는 일 | 남겨야 할 결과물 |
|---|---|---|
| 목표 설정 | 지원 직무와 채용 공고의 요구 역량 분석 | 목표 직무, 마감일, 역량 차이 |
| 설계 | 요구사항, ERD, API, 상태 전이 결정 | PRD 요약, ERD, API 초안 |
| 구현 | 기능별 Controller·Service·Repository·Entity 작성 | 실행 코드, 기능별 커밋 |
| 검증 | 성공·실패·권한·상태 전이 테스트 | 테스트 코드와 통과 명령 |
| 정리 | 선택 이유와 문제 해결 과정 기록 | README, 트러블슈팅, PR |
| 지원 | 프로젝트를 30초와 3분으로 설명 | 자기소개, 면접 카드, 지원 링크 |

## 기능 완료 기준

다음 항목을 모두 충족해야 기능 하나를 완료한 것으로 봅니다.

- [ ] 요구사항과 실패 조건을 본인 말로 설명했다.
- [ ] 실행 가능한 프로젝트에 직접 구현했다.
- [ ] 성공, 실패, 권한 또는 상태 전이 테스트를 작성했다.
- [ ] 테스트나 빌드 명령이 통과했다.
- [ ] 한 가지 의도로 설명 가능한 커밋을 남겼다.
- [ ] 설계 선택 또는 문제 해결 내용을 한 문단으로 기록했다.

빈칸의 답을 맞히거나 예제 코드를 읽은 것만으로는 완료가 아닙니다.

## 최종 졸업 기준

- [ ] 프로젝트를 처음 받은 사람이 README만 보고 실행할 수 있다.
- [ ] 로그인, 직원·부서, 휴가, 공지, 전자결재의 핵심 흐름이 동작한다.
- [ ] 주요 비즈니스 규칙을 검증하는 자동화 테스트가 있다.
- [ ] ERD와 API 명세가 실제 코드와 일치한다.
- [ ] 본인이 해결한 트러블슈팅을 최소 3건 설명할 수 있다.
- [ ] 핵심 설계 질문 8개에 각각 30초 안으로 답할 수 있다.
- [ ] 이력서나 포트폴리오에서 저장소, 데모, 문서 링크를 바로 열 수 있다.

세부 진행 순서는 [학습 워크북 안내](./practice/README.md)를 따릅니다.
